## Portfolio repository

This repository serves two purposes:

1. It is the source for my public GitHub profile README.
2. It contains the source code for my portfolio website.

The portfolio is a static-first site built with **Astro**, **TypeScript**, **Tailwind CSS**, and **MDX**, and deployed to **GitHub Pages** through GitHub Actions.

### Local development

```bash
nvm install
nvm use
npm ci
npm run dev
```

For the full verification suite:

```bash
npm run verify
```

The site is designed around a content-driven architecture, so projects and notes are maintained primarily through Markdown/MDX rather than page-specific frontend changes.

> The portfolio is an evolving professional asset. Published claims, projects, outcomes, and technical details are kept evidence-based rather than filled with placeholder content.
