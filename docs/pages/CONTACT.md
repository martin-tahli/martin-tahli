# CONTACT.md — `/contact`

## Goal

Make contacting Martin frictionless and professional.

Do not overdesign this page.

---

## 1. Primary layout

Use a spacious editorial composition with:

- page title
- one concise sentence about roles/consulting/collaboration
- primary email action when known
- LinkedIn
- GitHub
- optional WhatsApp later only if explicitly enabled

A contact form may be added later if it provides real value.

---

## 2. Visual treatment

Use one subtle systems/connection diagram or large typographic composition rather than stock contact imagery.

Terracotta can carry the primary CTA.

Cobalt may appear as one small technical node/detail.

---

## 3. Availability language

Do not claim availability, response time or location constraints unless explicitly confirmed in content data.

---

## 4. Form, if added

Fields:

- name
- email
- message
- optional context/company

No unnecessary fields.

Include explicit success/error states and spam protection appropriate for a static site.
