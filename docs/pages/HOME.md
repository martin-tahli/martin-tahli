# HOME.md — `/`

## Goal

Within 5–10 seconds, a recruiter/founder should understand:

1. Martin's positioning.
2. What he builds.
3. Why his approach differs.
4. Where the proof is.
5. How to contact him.

The homepage is the strongest expression of the **Precision Editorial — Warm Mono Hybrid** system.

---

## 1. Header

Use the global header from `COMPONENTS.md`.

Desktop: wordmark left, concise nav right.

Mobile: wordmark + menu.

---

## 2. Hero

### Desktop composition

Use an editorial 5/7 or similar asymmetric split.

Left/foreground:

- mono/uppercase eyebrow: `AI-NATIVE`
- large display headline: `Product & Systems Engineer`
- concise supporting positioning statement
- primary CTA: `View Work`
- secondary CTA: `Download CV`
- optional tertiary text link: `Contact`

Right/background:

- warm mountain/landscape visual or future equivalent
- strong negative space
- maximum one small human silhouette
- small technical/brand annotation such as `IDEAS / SYSTEMS / PEOPLE / REAL IMPACT`

Optional lower hero detail:

- small capability words
- restrained handwritten signature
- vertical/side editorial rule

Do not show invented metrics. The reference image contains demonstration metrics; production must hide them until real values exist.

### Mobile composition

- headline first
- body immediately below
- primary and secondary CTA stacked or 2-up only if comfortable
- image occupies lower portion of hero
- annotations reduced
- avoid text over visually busy image regions

---

## 3. Selected Work

Purpose: evidence, not portfolio decoration.

Structure:

- section index + `Selected Work`
- 2–3 featured projects
- one project may be wider/larger than the others
- real screenshots/diagrams when available
- concise metadata and clear `View case study →`

Avoid a uniform card grid if asymmetry makes the work stronger.

Private work is allowed and should be presented confidently with screenshots, architecture, demos and explanations where permitted.

---

## 4. How I Build

This is a key differentiator.

Present a horizontal or editorial flow:

1. Understand
2. Design
3. Build
4. Validate
5. Iterate

Supporting logic:

- understand user/problem/context
- design product + architecture
- build with AI leverage
- validate behavior/reliability/outcome
- iterate from evidence

Do not make this look like a generic 5-step agency process.

Use system-like lines, arrows, section numbering and concise copy.

## 5. Systems-flow visual break

This replaces the rejected statue/quote block.

Use a light technical composition on paper/grid background.

Concept:

`IDEAS → SYSTEMS → PEOPLE → IMPACT`

Visual possibilities:

- layered vertical planes
- nodes connected by paths
- input/processing/outcome flow
- subtle terracotta nodes
- one cobalt focal node

It should feel like an engineering/editorial graphic, not an infographic template.

No quote required.
